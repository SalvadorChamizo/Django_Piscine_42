How a Static Web Page is Displayed (Request → Response)

  1. User Request: A user types a URL into their browser (e.g., https://example.com/home) and presses Enter.
  2. HTTP Request Sent: The browser sends an HTTP request (usually a GET request) to the web server hosting the application.
  3. Routing: The web server or framework (e.g., Django, Flask, Express) receives the request and matches the URL to a specific route.
  4. View Function: The matched route calls a view (or controller). The view is responsible for handling the request logic. For a simple static page, the view does minimal work (no database calls).
  5. Template Selection: The view selects an HTML template file (e.g., "home.html").
  6. Template Rendering: The template engine processes the HTML file. If there are placeholders (variables), they are filled with data (even if minimal or none).
  7. HTTP Response: The rendered HTML is returned by the view as an HTTP response to the browser.
  8. Browser Rendering: The browser receives the HTML, parses it, and builds the DOM (Document Object Model).
  9. Page Displayed: The browser renders the page visually for the user, applying CSS and executing any JavaScript if present.

Summary Flow

Browser → HTTP Request → Server → Route → View → Template → Rendered HTML → HTTP Response → Browser → Display
