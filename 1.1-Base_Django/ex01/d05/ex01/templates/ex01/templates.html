Django Template Engine: How It Works

Django’s template engine combines static HTML with dynamic data passed from the view. It uses special tags and variables that are interpreted on the server before the final HTML is sent to the browser.

1. Template Rendering Process

  1. A view sends a context (dictionary of variables) to the template.
  2. The template is parsed by Django’s engine.
  3. Template syntax is evaluated.
  4. Final HTML is generated and returned to the browser.

2. Displaying Context Variables

Variables are inserted using double curly braces: 

    {% verbatim %}
    {{ username }}
    {{ age }}
    {% endverbatim %}

These placeholders are replaced with actual values from the context.

3. Blocks (Template Inheritance)

Blocks define sections that child templates can override. 

    {% verbatim %}
    <!-- base.html -->
    <body>
      {% block content %}
      Default content
      {% endblock %}
    </body>
    {% endverbatim %}
  
    {% verbatim %}
    <!-- child.html -->
    {% extends "base.html" %}
    {% block content %}
      <p>Custom page content</p>
    {% endblock %}
    {% endverbatim %}

4. Loops (for ... in)

Loop over collections: 

    {% verbatim %}
    {% for item in items %}
      <li>{{ item }}</li>
    {% endfor %}
    {% endverbatim %}

5. Conditional Statements (if)

Conditional rendering: 

    {% verbatim %}
    {% if user.is_authenticated %}
      <p>Welcome, {{ user.username }}!</p>
    {% else %}
      <p>Please log in.</p>
    {% endif %}
    {% endverbatim %}

Summary

Django templates allow clean separation of logic and presentation using variables, blocks, loops, and conditions—all processed safely on the server.
